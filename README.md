# GREEN-API Chat Client

Веб-приложение для отправки и получения текстовых сообщений через GREEN-API. Разработано в рамках тестового задания.

## Технологический стек
- **React 18** + **TypeScript**
- **Vite** (сборщик)
- **SCSS** (модульные стили, переменные Dart Sass)
- **REST API** (Fetch API, HTTP Polling)

## Функционал
- Авторизация по `idInstance` и `apiTokenInstance`
- Валидация и ввод номера телефона получателя
- Отправка текстовых сообщений (метод `sendMessage`)
- Автоматическое получение входящих сообщений (HTTP Polling через `receiveNotification` и `deleteNotification`)
- Адаптивный интерфейс в стиле мессенджера

## Инструкция по локальному запуску

1. Клонировать репозиторий:
```bash
git clone <ссылка-на-твой-репозиторий>
cd green-api-chat
```
2. Установить зависимости:
```bash
npm install
```
3. Запустить проект в режиме разработки:
```bash
npm run dev
```
4. Открыть в браузере адрес, указанный в консоли (обычно http://localhost:5173).
